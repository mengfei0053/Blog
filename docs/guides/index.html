1. GitHub CLI (gh) — 官方最强

📄️agent-browser-使用指南

agent-browser 是 Vercel Labs 开源的浏览器自动化 CLI，用 Rust 编写，专为 AI Agent 设计。核心特点是 Snapshot + Ref 机制 让 LLM 能精准操作网页，同时支持命令链式调用、批量执行、实时画面流、Dashboard 监控，以及多种云浏览器提供商接入。目前 34.8k Stars。

📄️cmux-使用指南

cmux 是基于 Ghostty 渲染引擎构建的原生 macOS 终端应用，核心卖点是垂直标签页管理、Agent 通知提醒环、内置浏览器、分屏面板和 CLI/socket 可编程 API。它不是 Ghostty 的 fork，而是一个独立的应用层。

📄️fresh-editor-入门使用指南

Fresh 是一个现代的、功能齐全的终端文本编辑器，用 Rust 编写，核心卖点是零配置开箱即用——把 VS Code/Sublime Text 的直观体验带到终端里，支持鼠标、命令面板、多光标、LSP、插件扩展，还能秒开多 GB 大文件。目前 GitHub 7.4k+ Stars。

📄️ghostty-入门使用指南

Ghostty 是 Mitchell Hashimoto（HashiCorp 创始人）用 Zig 语言编写的终端模拟器，核心卖点是原生性能 + GPU 加速渲染——启动极快、内存占用低、渲染流畅，同时保持原生应用体验（macOS 上不是 Electron 套壳，而是真正的 Cocoa App）。目前处于快速迭代期，macOS 和 Linux 均已可用。

📄️ragflow-使用指南

RAGFlow 是 infiniflow 团队开源的 RAG（检索增强生成）引擎，核心差异点是深度文档理解（DeepDoc）——能从复杂格式（PDF、扫描件、表格、幻灯片等）中精准提取结构化知识，配合多路召回+重排序，为 LLM 提供高质量、可溯源的上下文。目前 GitHub 81.6k Stars。

📄️symphony-入门使用指南

Symphony 是 OpenAI 开源的多 Agent 任务调度服务，核心卖点是让团队管理"工作"而不是"监督 Agent"——你只需要把任务放到 Linear 看板里，Symphony 会自动派发到独立的 workspace 中启动 Codex Agent 去完成，提交 PR，全程无需人工监督。GitHub Stars 已超过 24.9k，目前是工程预览版。

📄️tabby-入门使用指南

Tabby 是一款开源的跨平台终端模拟器，核心卖点是现代 UI + 一体化连接工具——不仅是一个终端，还内置了 SSH 客户端、串口终端、SFTP 文件传输，支持 Windows/macOS/Linux 三大平台。对需要同时管理本地终端和远程服务器的开发者来说，它是一个 all-in-one 的解决方案。目前 GitHub Stars 超过 60k。

📄️yazi-入门使用指南

Yazi 是用 Rust 编写的异步终端文件管理器（TUI file manager），核心卖点是全流程异步化——文件预览、图片缩略图、大文件浏览、搜索全部异步执行，不卡 UI。同时支持 Vim 式快捷键、图片预览、插件扩展、呼叫外部工具，是 ranger 的现代替代品。目前 GitHub Stars 超过 18k。
